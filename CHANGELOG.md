# Changelog

## 0.1.0

- Initial public TypeScript/JavaScript SDK and local reference app.
- Sandbox quote creation, plan selection, payment reference registration,
  binding and policy retrieval.
- Default payment simulator with success, decline, pending-then-success and
  rejected-reference scenarios.
- Page-memory idempotency recovery and bounded resource polling.
- Versioned standalone source ZIP and MIT license.

The SDK is not published to npm yet. Build it locally using the root workspace.
